# CI/CD Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitHub Actions CI (tests, builds, end-to-end, Lighthouse budgets), PR preview deploys, and gated production deploys of the public build to Netlify with a live smoke test. The repo becomes public with a protected `main`.

**Architecture:** Two workflows. `ci.yml` runs the three required checks. `deploy.yml` publishes PR previews and, after CI succeeds on `main`, the production site; both upload a locally built `dist/` with `netlify-cli --no-build`. A small Node smoke-test module, unit-tested with a fake `fetch`, verifies the live site after each production deploy.

**Tech Stack:** GitHub Actions, netlify-cli, @lhci/cli (Lighthouse CI), Vitest, Playwright, Node 22.

**Spec:** `docs/superpowers/specs/2026-10-03-ci-cd-design.md`

## Global Constraints

- Production serves the **public** build (`npm run build`). No `noindex`, no third-party brand images.
- Required status check job names are exactly `checks`, `e2e` and `lighthouse`.
- Lighthouse budgets: `categories:performance` ≥ 0.90 and `categories:accessibility` ≥ 0.95, mobile, median of 3 runs.
- Secrets: `NETLIFY_AUTH_TOKEN` is a repository **secret**; `NETLIFY_SITE_ID` = `6f251678-3b03-47f2-96f9-e5eeebf33bc4` is a repository **variable**. No token in code or logs.
- Workflows use least-privilege `permissions`, pinned major action versions, and Node from `.nvmrc`.
- Commit messages: plain, **no Claude attribution**. No em-dashes in user-facing text.
- Outward-facing steps (making the repo public, pushing, branch protection, production deploy) happen only in Task 7, which the user approved through the spec.

## Review Focus

1. **Secrets leaking:** the token must never be echoed. `netlify-cli` reads it from `NETLIFY_AUTH_TOKEN`, and no step prints env vars. Forked PRs must not get secrets (preview job guarded by the same-repo check).
2. **Deploying an untested commit:** production must check out exactly `workflow_run.head_sha` and only run when CI concluded `success` on a push to `main`.
3. **Lighthouse noise:** a flaky budget would block merges. The median of 3 runs with budgets set below today's scores (99/96) mitigates this; if CI hardware still flakes, rule on it rather than loosening silently.
4. **Pitch build in CI without the untracked brand files:** `npm run build:pitch` must still succeed, since missing images fall back to tiles at runtime and the build doesn't need them.
5. **Smoke test against a slow CDN:** retries for up to 60 s before failing, so a freshly published deploy isn't reported as broken.

- [ ] **Step 2: implement** `scripts/smoke-checks.mjs`:
  ```js
  // Post-deploy checks for the public site. Pure (fetch is injected) so it is unit-tested.
  export async function runSmokeChecks(baseUrl, { fetchFn = globalThis.fetch } = {}) {
    const base = baseUrl.replace(/\/$/, '');
    const failures = [];
    const home = await fetchFn(`${base}/`, { headers: { 'Cache-Control': 'no-cache' } });
    if (!home.ok) return { ok: false, failures: [`home page returned ${home.status}`] };
    const html = await home.text();
    if (!html.includes('Always ready for your')) failures.push('hero headline missing');
    if (/<meta name="robots" content="noindex">/.test(html)) failures.push('page has noindex (pitch build deployed?)');
    const dir = await fetchFn(`${base}/data/directory.json`);
    if (!dir.ok) failures.push(`directory.json returned ${dir.status}`);
    else {
      const { stores = [] } = await dir.json();
      if (stores.length < 100) failures.push(`directory.json has only ${stores.length} stores`);
    }
    const brand = await fetchFn(`${base}/assets/stores/jollibee-sariaya/logo.png`);
    if (brand.ok) failures.push('brand image is publicly served');
    return { ok: failures.length === 0, failures };
  }
  ```
  and the CLI `scripts/smoke.mjs`:
  ```js
  // Usage: node scripts/smoke.mjs <url> [--retries 6] [--delay 10000]
  import { runSmokeChecks } from './smoke-checks.mjs';

  const [url, ...rest] = process.argv.slice(2);
  if (!url) { console.error('usage: node scripts/smoke.mjs <url> [--retries N] [--delay ms]'); process.exit(2); }
  const opt = (name, fallback) => { const i = rest.indexOf(`--${name}`); return i >= 0 ? Number(rest[i + 1]) : fallback; };
  const retries = opt('retries', 6);
  const delay = opt('delay', 10000);

  for (let attempt = 1; attempt <= retries; attempt += 1) {
    let result;
    try { result = await runSmokeChecks(url); } catch (err) { result = { ok: false, failures: [`request failed: ${err.message}`] }; }
    if (result.ok) { console.log(`smoke ok: ${url}`); process.exit(0); }
    console.warn(`smoke attempt ${attempt}/${retries} failed: ${result.failures.join('; ')}`);
    if (attempt < retries) await new Promise((r) => setTimeout(r, delay));
  }
  process.exit(1);
  ```
  Add `"smoke": "node scripts/smoke.mjs"` to `package.json` scripts. Run the test; expect PASS.

### Task 5: `deploy.yml`

**Files:** Create `.github/workflows/deploy.yml`.

- [ ] **Step 1:**
  ```yaml
  name: Deploy
  on:
    workflow_run:
      workflows: [CI]
      types: [completed]
      branches: [main]
    pull_request:
  permissions:
    contents: read
  jobs:
    production:
      if: github.event_name == 'workflow_run' && github.event.workflow_run.conclusion == 'success' && github.event.workflow_run.event == 'push'
      runs-on: ubuntu-latest
      environment:
        name: production
        url: https://pakisuyoexpress.netlify.app
      concurrency: { group: deploy-production, cancel-in-progress: false }
      steps:
        - uses: actions/checkout@v4
          with: { ref: '${{ github.event.workflow_run.head_sha }}' }
        - uses: actions/setup-node@v4
          with: { node-version-file: .nvmrc, cache: npm }
        - run: npm ci
        - run: npm run build
        - name: Deploy to Netlify (production)
          run: npx --yes netlify-cli@27 deploy --prod --dir dist --no-build --site "$NETLIFY_SITE_ID" --message "main ${{ github.event.workflow_run.head_sha }}"
          env:
            NETLIFY_AUTH_TOKEN: ${{ secrets.NETLIFY_AUTH_TOKEN }}
            NETLIFY_SITE_ID: ${{ vars.NETLIFY_SITE_ID }}
        - name: Smoke test the live site
          run: npm run -s smoke -- https://pakisuyoexpress.netlify.app --retries 6 --delay 10000
    preview:
      if: github.event_name == 'pull_request' && github.event.pull_request.head.repo.full_name == github.repository
      runs-on: ubuntu-latest
      permissions:
        contents: read
        pull-requests: write
      concurrency: { group: 'preview-${{ github.event.pull_request.number }}', cancel-in-progress: true }
      steps:
        - uses: actions/checkout@v4
        - uses: actions/setup-node@v4
          with: { node-version-file: .nvmrc, cache: npm }
        - run: npm ci
        - run: npm run build
        - name: Deploy preview
          id: preview
          run: |
            npx --yes netlify-cli@27 deploy --dir dist --no-build --site "$NETLIFY_SITE_ID" --alias "pr-${{ github.event.pull_request.number }}" --message "PR #${{ github.event.pull_request.number }}" --json > deploy.json
            echo "url=$(node -p "require('./deploy.json').deploy_url")" >> "$GITHUB_OUTPUT"
          env:
            NETLIFY_AUTH_TOKEN: ${{ secrets.NETLIFY_AUTH_TOKEN }}
            NETLIFY_SITE_ID: ${{ vars.NETLIFY_SITE_ID }}
        - name: Comment the preview link
          uses: actions/github-script@v7
          env: { PREVIEW_URL: '${{ steps.preview.outputs.url }}' }
          with:
            script: |
              const marker = '<!-- netlify-preview -->';
              const body = `${marker}\n**Preview:** ${process.env.PREVIEW_URL}\nBuilt from ${context.payload.pull_request.head.sha.slice(0, 7)}.`;
              const { owner, repo } = context.repo;
              const issue_number = context.payload.pull_request.number;
              const comments = await github.paginate(github.rest.issues.listComments, { owner, repo, issue_number });
              const existing = comments.find((c) => c.body?.includes(marker));
              if (existing) await github.rest.issues.updateComment({ owner, repo, comment_id: existing.id, body });
              else await github.rest.issues.createComment({ owner, repo, issue_number, body });
  ```
